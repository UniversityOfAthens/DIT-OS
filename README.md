## Compilation

To compile DIT-OS, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/UniversityOfAthens/DIT-OS.git
   ```

2. Navigate to the project directory:
   ```bash
   cd DIT-OS
   ```

3. Build the project using the provided Makefile:
   ```bash
    make
   ```
